# 계정 정책의 법령과 서비스 조건 확인

이 문서는 001 계정 요구사항의 확인 질문을 정하려고 2026-11-19에 확인한 법령 조문과 Supabase·카카오 문서의 내용을 기록한다. 연령 확인 방법, 광고 수신 동의, 탈퇴 데이터 파기와 보존, 유출 통지, 약관 변경, 로그인 세션 유지에 관한 결정이 어떤 사실을 근거로 삼았는지 이 문서에서 확인할 수 있다.

## 범위

이 문서는 2026-11-19에 확인한 내용을 그 시점 기준으로 고정한 기록이다. 이후에는 본문을 고치지 않으며, 정정할 내용이 생기면 문서 끝에 정정 기록을 덧붙인다.

- 이 문서는 법률 자문이 아니다. 해석이 필요한 항목은 '확인하지 못함'으로 따로 적었다.
- 법령은 국가법령정보센터 본문을 브라우저로 열어 조문을 확인했다.
- PDF와 HWP로만 제공되는 개인정보보호위원회 안내서, 처리방침 작성지침, 공정거래위원회 표준약관 본문은 열지 않았다.

## 연령 확인

| 내용 | 판정 | 출처 |
|---|---|---|
| 개인정보 보호법 제22조의2는 만 14세 미만 아동의 개인정보를 처리할 때 법정대리인의 동의를 받고 확인하게 한다. 만 14세 이상인지 확인하는 방법을 정한 조문은 없다. | 확인함 | [개인정보 보호법 제22조의2](https://www.law.go.kr/법령/개인정보보호법/제22조의2) |
| 법정대리인 동의를 확인하는 방법은 시행령 제17조의2제1항의 일곱 가지이며, 휴대전화 본인인증은 그 가운데 하나다. | 확인함 | [개인정보 보호법 시행령 제17조의2](https://www.law.go.kr/법령/개인정보보호법시행령/제17조의2) |
| 나이와 본인 여부를 반드시 확인해야 하는 경우는 청소년유해매체물을 제공할 때다. | 확인함 | [청소년보호법 제16조](https://www.law.go.kr/법령/청소년보호법/제16조), [같은 법 시행령 제17조](https://www.law.go.kr/법령/청소년보호법시행령/제17조) |
| 카카오싱크 간편가입에는 '만 14세 이상 연령 동의' 약관을 추가하는 선택 항목이 있다. 카카오 로그인으로 연령대나 출생 연도를 받으려면 비즈 앱 전환과 동의항목 심사가 필요하다. | 확인함 | [카카오 로그인 활용 문서](https://developers.kakao.com/docs/ko/kakaologin/utilize#scope-user), [사전 설정 문서](https://developers.kakao.com/docs/ko/kakaologin/prerequisite#additional-features) |
| 개인정보보호위원회 「아동·청소년 개인정보 보호 안내서」(2024.12)가 연령 확인 방법을 권고하는지 | 확인하지 못함 | PDF 본문을 열지 않았다 |

## 광고성 정보 수신 동의

| 내용 | 판정 | 출처 |
|---|---|---|
| 수신 동의를 받은 자는 동의를 받은 날부터 2년마다 수신 동의 여부를 확인해야 한다. 확인할 때 전송자 명칭, 동의 사실과 날짜, 동의를 유지하거나 철회하는 방법을 알린다. | 확인함 | [정보통신망법 제50조](https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률/제50조), [같은 법 시행령 제62조의3](https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률시행령/제62조의3) |

## 탈퇴 데이터의 파기와 보존

| 내용 | 판정 | 출처 |
|---|---|---|
| 보유 기간이 지나거나 처리 목적을 달성한 개인정보는 지체 없이 파기한다. 다른 법령에 따라 보존하는 정보는 분리해서 저장한다. | 확인함 | [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법) 제21조 |
| 표준 개인정보 보호지침 제10조는 불필요하게 된 때부터 5일 이내에 파기하게 한다. | 확인함 | [표준 개인정보 보호지침](https://www.law.go.kr/행정규칙/표준개인정보보호지침) |
| 통신비밀보호법 시행령 제41조는 전기통신사업자에게 인터넷 로그기록자료와 접속지 추적자료를 3개월 이상 보관하게 한다. | 확인함 | [통신비밀보호법 시행령 제41조](https://www.law.go.kr/법령/통신비밀보호법시행령/제41조) |
| 뜨개 기록 웹 서비스가 위 보관 의무를 지는 전기통신사업자에 해당하는지를 밝힌 공식 해석 | 확인하지 못함 | |
| 탈퇴 뒤에도 동의 기록을 보존하게 하는 법령 | 찾지 못함 | |

| 유출 가능성 통지는 시행령 제39조의3제1항에 따라 72시간 안에 한다. | 확인함 | [개인정보 보호법 시행령 제39조](https://www.law.go.kr/법령/개인정보보호법시행령/제39조) |

## 약관과 처리방침 변경

| 내용 | 판정 | 출처 |
|---|---|---|
| 약관규제법과 전자상거래법에는 약관을 바꿀 때의 공지 기간을 정한 조문이 없다. | 확인함 | [약관규제법](https://www.law.go.kr/법령/약관의규제에관한법률), [전자상거래법](https://www.law.go.kr/법령/전자상거래등에서의소비자보호에관한법률) |
| 공정거래위원회는 불리하거나 중요한 약관 변경에 30일 전 공지와 개별 통지가 필요하다고 보고 주요 플랫폼 약관을 시정했다. | 확인함 | [정책브리핑 2019-03](https://www.korea.kr/news/policyNewsView.do?newsId=148859180) |
| 개인정보 수집·이용 목적, 항목, 보유 기간이 바뀌면 다시 동의를 받아야 한다. | 확인함 | [개인정보 보호법](https://www.law.go.kr/법령/개인정보보호법) 제15조제2항 |
| 전자상거래 표준약관의 '시행 7일 전 공지' 조항 | 확인하지 못함 | HWP 첨부를 열지 않았다 |
