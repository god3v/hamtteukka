# 브랜드와 말투

이 문서는 함뜨까가 화면에서 주는 인상과 화면 문구의 말투를 정한다. 화면을 만들거나 문구를 쓰는 사람은 이 문서에서 서비스 이름 표기, 워드마크, 문구 유형별 문형, 숫자와 날짜 표기, 용어를 확인할 수 있다. 색, 글꼴, 컴포넌트 규칙은 [비주얼 시스템](visual-system.md)이 정한다.

## 서비스 인상

함뜨까는 뜨개를 기록하는 깔끔한 도구다. 흰 바탕과 무채색 UI 위에 테라코타 강조 색 하나만 쓴다. 뜨개의 따뜻함은 이 강조 색과 해요체 말투, 사용자가 올린 작품 사진으로 전한다.

| 지킬 것 | 피할 것 |
|---|---|
| 흰 바탕, 구분선으로 나눈 목록, 넉넉한 여백 | 일러스트, 그라데이션, 털실 질감 같은 장식 |
| 한 화면에서 강조 색을 쓰는 주요 행동 하나 | 여러 색을 쓴 카드와 배지 |
| 작품 사진이 화면의 색을 맡게 하기 | 사진 위에 색 필터나 장식 테두리를 덧입히기 |
| 짧고 구체적인 문구 | 감탄사, 이모지, 느낌표 |

이 방향을 고른 이유와 함께 검토한 다른 분위기는 [ADR-0014](../decisions/0014-design-direction.md)에 있다.

## 이름과 워드마크

- 서비스 이름은 한글 `함뜨까`로 쓴다. 영문 표기 `hamtteukka`는 주소, 저장소, 패키지 이름처럼 한글을 쓸 수 없는 곳에서만 쓴다.
- 워드마크는 Pretendard ExtraBold(800)로 쓴 `함뜨까` 글자이며 색은 `ink` 토큰이다. 워드마크에는 강조 색이나 장식을 더하지 않는다.
- 로고 심벌과 앱 아이콘은 아직 정하지 않았다. 결정 시점은 [의사결정 기록](../decisions/README.md)의 미결정 항목 OD-20에서 관리한다.

## 말투

화면 문구는 해요체로 쓴다. 이 규칙은 사용자가 화면에서 보는 문구에만 적용한다. 저장소 문서는 [헌법 P-15](../constitution.md)에 따라 평서체로 쓰고, PR 본문은 [AGENTS.md](../../AGENTS.md)의 PR 작성 규칙에 따라 합쇼체로 쓴다.

| 문구 유형 | 문형 | 예시 |
|---|---|---|
| 버튼 | 행동을 나타내는 짧은 명사형 | 저장, 삭제, 새 프로젝트, 되돌리기 |
| 확인 창 제목 | 할 일을 묻는 해요체 질문 | 카운터를 0단으로 되돌릴까요? |
| 확인 창 버튼 | '확인' 대신 실행할 행동 | 되돌리기, 삭제 |
| 완료 알림 | 끝난 일을 과거형 해요체로 | 48단까지 저장했어요. |
| 오류 | 하지 못한 일과 사용자가 할 일을 차례로 | 저장하지 못했어요. 연결을 확인하고 다시 시도해 주세요. |
| 빈 화면 | 지금 상태와 다음 행동 | 아직 프로젝트가 없어요. 첫 작품을 기록해 보세요. |
| 안내 | 알려야 할 사실을 해요체로 | 이 브라우저에만 저장돼요. |

- 오류 문구는 사용자를 탓하지 않는다. 오류 코드가 필요하면 문구 뒤에 작게 붙인다.
- 한 문장에는 한 가지 내용만 담는다. 두 가지를 알려야 하면 문장을 나눈다.
- 같은 행동은 모든 화면에서 같은 낱말로 부른다. 예를 들어 지우는 행동은 `삭제`로 쓰고 `제거`와 섞지 않는다.

## 숫자와 날짜

| 항목 | 표기 | 예시 |
|---|---|---|
| 단수 | 숫자 뒤에 `단`을 붙인다 | 45단 |
| 반복 위치 | `n세트 m단`으로 쓴다([003 요구사항](../specs/003-row-counter/requirements.md) FR-25) | 12세트 1단 |
| 날짜 | 올해 날짜는 `M월 D일`, 다른 해의 날짜는 `YYYY년 M월 D일`로 쓴다 | 11월 2일, 2025년 3월 8일 |
| 시각 | 12시간제에 오전과 오후를 붙인다 | 오후 3:42 |
| 지난 시각 | 1분 안은 `방금`, 1시간 안은 `n분 전`, 오늘은 `n시간 전`, 어제는 `어제`, 7일 안은 `n일 전`, 그보다 오래되면 날짜로 쓴다 | 3분 전, 어제, 3일 전 |
| 파일 크기 | 소수 첫째 자리까지 쓰고 단위는 KB, MB를 쓴다 | 2.4MB |

## 용어

| 용어 | 뜻 | 대신 쓰지 않는 말 |
|---|---|---|
| 프로젝트 | 뜨고 있거나 다 뜬 작품 하나의 기록 | 작업, 작품 기록 |
| 뜰 예정 | 아직 시작하지 않고 다음에 뜨려고 계획해 둔 프로젝트의 상태. 다음에 뜰 작품을 담는 목록을 따로 두지 않는다([002 요구사항](../specs/002-projects/requirements.md) Q-08) | 위시리스트, 큐, 대기열 |
| 카운터 | 단수를 세는 도구. 프로젝트 안의 카운터에는 몸판, 소매처럼 이름을 붙인다 | 계수기 |
| 퀵 카운터 | 로그인하지 않아도 쓰고 값을 브라우저에 저장하는 카운터 | 임시 카운터 |
| 이어서 뜨기 | 마지막으로 센 카운터로 바로 돌아가는 바 | 최근 카운터 |
| 도안 자료 | 프로젝트에 붙인 PDF, 웹 링크, 영상 링크 | 첨부 파일 |
| 게이지 | 정해진 길이 안에 들어가는 코 수와 단 수. 세탁 전과 세탁 후로 나눠 기록한다 | 밀도 |
